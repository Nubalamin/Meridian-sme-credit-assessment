# Meridian-sme-credit-assessment
SME Credit Assessment System – Systems Analysis and Design Project
Meridian Community Bank – SME Credit Assessment System

1. Project Overview

The Meridian Community Bank SME Credit Assessment System is a Systems Analysis and Design project focused on improving how the bank receives, organises and assesses loan applications from Small and Medium-sized Enterprises (SMEs).

The proposed system aims to reduce manual work, improve application tracking, identify missing information and support credit officers in making informed decisions.

2. Project Objectives

The main objectives are to:

Improve the collection and management of SME loan applications.

Identify missing or unclear application information.

Organise financial transactions and generate cash-flow summaries.

Display risk indicators with supporting evidence.

Improve application tracking and processing.

Support authorised credit officers in recording credit decisions.

Maintain records of important activities and changes.

3. Main System Modules

The proposed system includes:

Application Management: Captures applicant and business information and assigns unique application references.

Document Management: Supports document uploads and manual entry of information.

Completeness Checking: Identifies missing, unclear or inconsistent information.

Financial Assessment: Organises transactions and generates cash-flow summaries.

Risk Evidence: Displays financial risk indicators and their supporting information.

Decision Management: Allows authorised officers to record credit decisions and reasons.

Workflow and Notifications: Tracks application progress and outstanding information.

Reporting and Audit: Provides operational reports and records important system activities.

4. Technology Stack

The planned technologies are:

Frontend: HTML, CSS and JavaScript.

Backend: PHP.

Database: MySQL.

Local development environment: XAMPP.

Version control and collaboration: Git and GitHub.

5. Important System Principles

Credit decisions must remain with authorised human officers.

Missing documents or information must be flagged for correction, not automatically rejected.

Risk indicators must show the evidence supporting them.

User access must be controlled according to assigned roles.

Important activities and changes must be recorded for accountability.

External banking and credit bureau integrations will be simulated using sample data where actual access is unavailable.

6. Project Scope

This repository contains the coursework design and functional prototype of the proposed SME Credit Assessment System.

The prototype will demonstrate the main process, from application capture and document checking to financial assessment, risk evidence and recording credit decisions.

It is not a live banking system and will use fictional sample applicant information.
